## 🎬 2つの動画制作モード：Model Engine vs Code Engine

**同じ棒人間ディレクターで、2つの映像制作ルート**。Aモードは動画生成モデルで連続したショットを生成し、Bモードはコードで素材を動かしてレイヤーアニメーションを制作します。どちらもAIエージェントによる完成動画までの自動制作に対応し、選んだ画風の仕様に沿って仕上げます。

アイデア、記事、Webページのリンク、完成した脚本のいずれからでも制作を始められます。どちらのモードも短い動画から長尺コンテンツまで対応し、公開先に合わせて `16:9` の横型または `9:16` の縦型を選べます。字幕、ナレーション、BGM、効果音は、要望と画風の仕様に合わせて構成します。

<a id="quick-start"></a>

## 🧭 はじめに

<strong>掲載サンプルにできるだけ近い仕上がりを目指すなら、CodexやClaude Codeなど、プログラミングに強いAIツールをおすすめします。</strong>

ファイルの読み書きとターミナル実行ができるほかのAIエージェントにもインストールできます。ただし、モデルの能力、ツールの設定、実行方法によって仕上がりは異なる場合があります。

### Step 1：Skillをインストール

初回は必要な設定を確認し、不足しているものと設定方法を順に案内します。次の内容をAIアシスタントに送ってください：

```text
このSkillをインストールしてください：
https://github.com/kaomei/stickman-video-director

インストール後にSKILL.mdを読み、準備ができたことを教えてください。
```

ターミナルを使いたい場合や、インストールがタイムアウトした場合は、[手動インストールガイド](skills/directing-stickman-videos/references/installation-troubleshooting.md)も参考にできます。

### Step 2：画風とモードを選び、ひと言で制作をスタート

「[Aモード](#a-styles)」または「[Bモード](#b-styles)」から好きな画風を選び、下の対応するプロンプトをコピーして、自分の要望に書き換えてAIアシスタントに送ってください：

<a id="director-start"></a>

### A · Model Engine

```text
Model Engine（Aモード）を使って、次のテーマ／文章を棒人間動画にしてください：
[テーマを入力するか、文章を貼り付けるか、アイデアをそのまま説明]

条件：横型16:9、画風はA3「原始時代・洞窟スタイル」、まずは30秒。

最初にストーリー構成、音の方向性、絵コンテ案を提示してください。
私が承認した後、各シーンを単独で生成できる動画生成プロンプトを提供してください。
```

- **制作の流れ：** 絵コンテの承認後は、自分で生成することも、エージェントに内蔵ブラウザで操作してもらうこともできます。まず低解像度で試作し、仕上がりに納得してから制作と編集を続けます。
- **推奨プラットフォーム：** サンプルに近い仕上がりを目指すならGoogle Flowをおすすめします。初めての制作には[Xの詳しいチュートリアル](https://x.com/CrazyKaomei/status/2102311241046008268)も参考にしてください。

<a id="autopilot-start"></a>

### B · Code Engine

```text
Code Engine（Bモード）を使って、次のテーマ／記事を魅力的な棒人間動画にしてください：
[長文、ニュース、リンクを貼り付けるか、作りたいテーマを説明]

条件：横型16:9、長さ8分、画風はB1「ミニマル線画」。ナレーション、字幕、効果音も付けてください。

最初にローカルの画像生成・動画合成環境を確認し、全編の脚本と冒頭20秒の音声付きサンプルを提示してください。
承認後は、全編の素材準備、コード作成、ローカルレンダリングを自動で進め、完成動画を納品してください。
```

- **制作の流れ：** 脚本と20秒の音声付きサンプルを承認すると、エージェントが選んだ画風に沿って素材、アニメーション、字幕、音を制作し、全編をローカルでレンダリングしてプレビューを提供します。
- **部分調整：** 完成後に映像や音を変えたい場合は、承認済みの部分を残して、該当するシーンだけをAIに調整してもらえます。

### Step 3：サムネイルと公開用テキストをワンステップで生成

完成動画に納得したら、[サムネイル＆公開キット](#thumbnail-publishing-kit)の制作に進めます。次のひと言をAIに送ってください：

```text
今の動画のサムネイルと公開用テキストを、承認済みの画風で作成してください。
```

AIが画風に合ったサムネイル画像、動画タイトル、概要欄、固定コメントをまとめて生成します。モードの切り替えや再設定は不要です。

## 🎨 A · Model Engineの画風一覧

現在のAモードのサンプルは[Google Flow](https://flow.google.com/)で制作しています。ほかの動画生成プラットフォームも選べます。<strong>エージェントに自動制作を任せる前に、アカウントにログイン済みで、利用可能なクレジットがあることを確認してください。</strong>

A1、A2、A3…の順に追加し、各画風に対応するアニメーションのサンプルを掲載します。

<a id="a1"></a>

### A1：クラシック白黒

丸い頭と数本の線だけで、難しい話が腑に落ちる。不安は檻に、注意力は残り少ない電池に。余計な装飾をなくすほど、表情とたとえが際立ちます。

### キットの内容：

- **サムネイル画像**: 承認済みのキャラクター、画風、配色、物語の対立に合わせた横長 16:9 の画像 1 枚。対応する画像生成ツールが利用でき、必要な費用が承認されていれば直接生成します。
- **高クリック率を狙うタイトル 5 案**: 検索意図、好奇心を刺激する情報のギャップ、幅広い視聴者への訴求を考慮。
- **YouTube Studio の説明文＆SEO**: 内容の要約、関連タグ、最終動画または確認済みタイムラインに基づくタイムスタンプを用意。
- **固定コメント用フック**: 動画に関連した、自然な対話を促す質問 1 件。
- **公開前チェックリスト**: モバイルのセーフゾーン、コントラスト、内容の正確さ、素材の権利確認状況。Content-ID の通過や収益化資格は保証しません。

### 呼び出し方：

最終動画を承認すると、アシスタントがこの任意の仕上げパックを提案します。同意すれば続行し、不要なら動画の納品を遅らせずに終了できます。プロンプトのコピーは不要です。直接依頼することもできます：

```text
この動画のサムネイル＆公開キットを生成してください：
- 承認済みの画風に合う、横長 16:9 のサムネイル画像 1 枚
- YouTube タイトル 5 案
- 説明文、関連タグ、根拠がある場合は確認済みタイムスタンプ
- 固定コメント用の、反応を引き出す質問 1 件
- 未確認項目を明記した公開前チェックリスト
```

*画像生成には利用可能なツールと必要な費用承認が必要です。利用できない場合は制約を説明し、テキスト部分を先に納品します。承認済み脚本から先に依頼した場合は下書きとし、最終動画に依存する確認は保留します。画像をダウンロードし、文章を YouTube Studio や TikTok に必要に応じてコピーしてください。自動アップロード・公開は行いません。*

## ❓ よくある質問

### Q1. 本当に100%無料ですか？ 隠れた料金はありますか？

はい、Skill 自体は無料です。MIT ライセンスのオープンソースで、個人利用にも商用プロジェクトにも使え、月額30〜60ドルの SaaS とは違ってサブスク料金はかかりません。隠れた費用はありませんが、接続するサービスにはそれぞれ料金がかかります。AI エージェントのプラン（Codex や Claude Code など）、画像や音声のための外部 API の利用料金（Google Gemini や ElevenLabs など）、そして Model Engine（A）では Google Flow などで動画を生成するためのクレジットです。

<!-- readme:platforms -->

### Q2. キャラクターの一貫性を保つにはどうすればよいですか？

**B · Code Engine**：コードで制作を進めるワークフローです。動画制作の前にキャラクターの画像素材を生成し、各シーンで再利用するため、外見の一貫性は比較的安定します。

**A · Model Engine**：主にテキストから動画を生成します。髪型や服装などが複雑で、文章だけでは安定して再現しにくい場合は、棒人間キャラクターの参照画像を1枚追加し、後続のクリップでも使い続けると、より安定した結果が得られます。

### Q3. おすすめのツールは何ですか？特定の画像生成モデルが必要ですか？

デモに近い仕上がりを目指すなら、**AモードではGoogle Flow でクリップを生成し、BモードではCodexで動画全体を制作するのがおすすめです。** Bモードのデモはすべて Codex で制作しました。作りたい動画を普段の言葉で伝えれば、エージェントがコードを書き、ローカルでレンダリングします。

**画像生成モデルは自由に選べます。** Bモードのデモの画像素材は Codex 内蔵の画像生成ツールで作成しており、別途画像生成 API を設定する必要はありません。ファイルの読み書きやターミナルでのコマンド実行に対応した Claude Code などのエージェントに、使い慣れた画像生成・音声合成ツールを組み合わせることもできます。まずは音声付きの短い試作で画風・字幕・音を確認してから、本編を制作するのがおすすめです。

### Q4. 台本がなくても動画を作れますか？

はい。大まかなアイデア、ふと思いついたこと、ニュースのリンク、ブログ記事全文を貼り付けるだけでも始められます。AI ディレクターが中心となる対立を抽出し、引きつける3秒のフックを作り、題材・目標の長さ・選んだスタイルに合わせて物語とカットを構成します。笑いの間やナレーションの指示も加えます。

### Q5. 退屈さを避け、視聴者が見続ける動画にする仕組みは？

一般的な AI ツールは文章をそのまま絵にするだけです。Stickman Video Director は本格的な**視覚的ストーリーテリングの心理学**を活用します：

- **3秒のフック**：最初の一文を、すぐに伝わる視覚的な矛盾や好奇心を刺激する謎に変え、スクロールを止めます。
- **視覚的な比喩**：退屈な抽象概念を視覚的なギャグに変えます。不安を縮んでいくハムスターの回し車で、燃え尽きを残量1%のバッテリーで表現する、といった方法です。
- **テンポと笑いの間**：構造化された間、リアクションショット、効果音の指示（SFX）を挿入し、Casually Explained のようなクリエイターの笑いのテンポを再現します。

### Q6. YouTube や TikTok で収益化できますか？

はい、動画はあなたのものとして公開・収益化できます。顔出しなしのクリエイターが気にするのは、YouTube の「Reused Content（再利用されたコンテンツ）」ポリシーです。本プロジェクトは動画ごとに台本、テンポ、画面演出を作り、素材の使い回しはしません。これは再利用コンテンツの判定で重視される点です。ただし、YouTube Partner Program（YPP）や TikTok Creator Rewards Program の承認は、チャンネル全体を見て各プラットフォームが判断します。自分の視点や声を加え、継続的に投稿し、AI 生成コンテンツに関する各プラットフォームのルールに従ってください。

### Q7. プログラミングの知識や高価な GPU は必要ですか？

自分でコードを書いたり、高性能な GPU を購入したりする必要はありません。Aモードはオンラインの動画生成サービスを利用でき、Bモードはエージェントがコードを書いてローカルでレンダリングします。制作速度はパソコンの性能に影響されますが、それだけで決まるわけではありません。
