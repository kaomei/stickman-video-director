# 🎬 Stickman Video Director

**どんな脚本も、顔出しなしのYouTubeチャンネルでバズる、多彩な画風の棒人間アニメ動画に。**

[![GitHub Stars](https://img.shields.io/github/stars/kaomei/stickman-video-director?style=flat-square)](https://github.com/kaomei/stickman-video-director/stargazers)
![MIT License](https://img.shields.io/badge/License-MIT-16a34a?style=flat-square)

トピック、記事、台本から始められます。ビジュアル、ナレーション、字幕、効果音を自動で組み合わせ、公開できる棒人間動画に仕上げます。

**⚡ 100% 無料・オープンソース。顔出しも月額50ドルのサブスクも不要。何日もかけず、数分で完成。**

**科学解説、ダーク心理学、テクノロジー寓話、話題の逸話、ストーリーテリング系チャンネル**向けの画風を継続的に追加しています。

## 🎬 2つの動画制作モード：Model Engine vs Code Engine

**同じ棒人間ディレクターで、映像制作のルートは2つ**：A モードは動画生成モデルで連続したショットを作り、B モードはコードで素材を動かしてレイヤーアニメーションを作ります。どちらも、対応するツールを備えた Agent が完成動画まで自動制作でき、選んだ画風の仕様に沿って仕上げます。

<a id="quick-start"></a>

## 🧭 使い始める

<strong>展示されている作例にできるだけ近い仕上がりを目指すなら、Codex、Claude Code など、プログラミング能力の高い AI ツールを優先して使うことをおすすめします。</strong>

ファイルの読み書きとターミナル実行ができる他の Agent にもインストールできます。ただし、モデルの能力、ツール設定、実行方法によって仕上がりは異なる場合があります。

次の内容を AI アシスタントに送ってください：

```text
このSkillをインストールして：
https://github.com/kaomei/stickman-video-director

インストールできたら、すぐにインストール先のSKILL.mdを読み、
2つのモードで受け取れるもの、必要なツール、制作の流れを
分かりやすく説明し、そのまま使える依頼文の例を教えてください。
私の作りたい動画に合わせて、足りないものと次にすることも具体的に案内してください。
```

インストールがタイムアウトした場合は、[インストールのトラブルシューティング](skills/directing-stickman-videos/references/installation-troubleshooting.md)（macOS/Linux・Windows）をご覧ください。

<a id="director-start"></a>

### A · Model Engine（モデルエンジン）：プロンプトの受け取り、または完成までの制作を選ぶ

**ルート1：通常のチャットで、絵コンテと単独で使えるプロンプトを受け取る。** インストール後、テーマを書き換えて次の文章を AI アシスタントに送ってください。

```text
Model Engine／Aモードで、次のテーマ・原稿・要望を
棒人間動画にしてください：
[テーマを書く、原稿を貼る、または作りたい内容を説明する]

条件：横長16:9、A3「原始時代・洞窟スタイル」で、まずは30秒。
先に演出プランを見せて、確認してからクリップごとの動画プロンプトを出してください。
```

**流れ：テーマと要望を伝える → 物語と絵コンテのプランを確認する → 必要に応じて人物の参考画像を確認する → 単独で使えるプロンプトを受け取る → 自分でクリップを生成し、編集して仕上げる。**

演出プランには、物語の構成、場面ごとのナレーション、動作、カメラワーク、サウンドデザインが含まれます。プロンプトを受け取ったら、[Google Flow](https://flow.google.com/) などの動画生成ツールに順番に入力し、CapCut などで字幕を付け、編集して仕上げます。

**ルート2：ターミナル実行ができる Agent に、完成動画まで制作してもらう。** 自動で制作を進めたい場合は、次の依頼を追加してください。

```text
今回はAgentによる自動制作ルートを選び、原則として内蔵ブラウザからGoogle Flowを開いて生成してください。
まずブラウザ、Flowのログインと利用枠、ファイル操作と編集ツールを確認し、
制作プラン、使うツール、費用、実行範囲をまとめて説明してください。
確認後は、許可した範囲で生成、必要な部分の修正、編集、ローカルプレビューまで続けて進め、
要望と選んだ画風に合わせて字幕と音も制作してください。
クリップごとの指示を待たずに進め、ツールが足りない場合や、プラン変更・費用増額が必要な場合に説明してください。
```

**流れ：プランと実行範囲を確認する → クリップを生成・確認する → 必要な部分を修正する → 編集・仕上げを行う → ローカルプレビューを受け取る。** 字幕、音、プロンプトは要望と選んだ画風の基準に合わせて制作し、確認済みの人物、素材、合格したクリップは再利用します。

初めての動画は、[X のビジュアル制作ガイド](https://x.com/CrazyKaomei/status/2102311241046008268)（ステップごとの動画デモ付きスレッド）を参考に作ってみてください。

<a id="autopilot-start"></a>

### B · Code Engine（コードエンジン）：ひと言の依頼から長編動画へ

Codex や Claude Code など、ファイル操作とコマンド実行ができる環境にインストールしたら、次のように依頼します。

```text
Code Engine／Bモードで、次のテーマ・記事・投稿・ニュース・具体的な要望から、
YouTubeで興味を引く動画を作ってください：
[内容やリンクを貼る、または紹介・宣伝したい内容を説明する]

条件：5〜10分、横長16:9、B1「ミニマル線画」。ナレーション、字幕、効果音を付けてください。

まず画像生成・音声合成・動画合成の設定を確認し、台本と音声付きの20秒プレビュー動画を見せてください。
確認後は、映像をナレーションのテンポに合わせて全編を自動制作し、完成動画ファイルを納品してください。
クリップごとの生成や組み立てを、こちらで行わずに済むようにしてください。
```

**流れ：テーマ・内容・要望を伝える → 台本を確認する → 音声付きの20秒プレビュー動画を確認する → 全編を自動制作する → 完成動画を受け取る**

AI アシスタントが内容に合った絵コンテを作り、映像とナレーションを生成。字幕と効果音を加え、音声のテンポに合わせて一本の動画に仕上げます。主に確認するのは台本とサンプルで、クリップごとの生成や手作業での組み立ては不要です。

初回は必要な設定を確認し、不足しているものと準備方法を順番に案内します。映像や声が気になったら、その部分だけを調整し、確認済みの部分は残せます。

<strong>どちらのモードでも選べる仕上げ：</strong>完成動画に満足したら、[サムネイル＆公開キット](#thumbnail-publishing-kit)で画風に合ったサムネイルと投稿文を作ることも、そのまま終了することもできます。モードの切り替えや再インストールは不要です。

### B5: キャラクター解説

お気に入りのアバターを、チャンネルの語り手に。有名なキャラクターを使う場合は許諾が必要です。画面の隅で主役が語り、左側では棒人間がアイデアを小さな劇に変えます。請求書に引きずられたり、プレッシャーに押しつぶされたり——抽象的な話にも、笑いと記憶に残る場面が生まれます。

- **映像の魅力**: 温かい紙の質感、個性のある語り手、黒と赤の強調文字。大げさな重み、反動、小道具の変形で、言葉を視覚的なたとえに変えます。
- **音の雰囲気**: 明瞭なナレーションを軸に、口の動き、表情、字幕を音声に合わせます。効果音は動作の決めどころに置き、控えめな音楽で声を引き立てます。
- **おすすめの内容**: 知識解説、身近な心理、日常の気づき、ポップカルチャー、ユーモラスなコメント。

*すべてのサムネイル案は、実績のある YouTube のパッケージング心理学を軸に設計しています。大胆な視覚的矛盾、明快なシルエット、スマホでも読みやすい文字を重視します。*

### キットの内容：

- **サムネイル画像**: 承認済みのキャラクター、画風、配色、物語の対立に合わせた横長 16:9 の画像 1 枚。対応する画像生成ツールが利用でき、必要な費用が承認されていれば直接生成します。
- **高クリック率を狙うタイトル 5 案**: 検索意図、好奇心を刺激する情報のギャップ、幅広い視聴者への訴求を考慮。
- **YouTube Studio の説明文＆SEO**: 内容の要約、関連タグ、最終動画または確認済みタイムラインに基づくタイムスタンプを用意。
- **固定コメント用フック**: 動画に関連した、自然な対話を促す質問 1 件。
- **公開前チェックリスト**: モバイルのセーフゾーン、コントラスト、内容の正確さ、素材の権利確認状況。Content-ID の通過や収益化資格は保証しません。

### 呼び出し方：

最終動画を承認すると、アシスタントがこの任意の仕上げパックを提案します。同意すれば続行し、不要なら動画の納品を遅らせずに終了できます。プロンプトのコピーは不要です。直接依頼することもできます：

```text
この動画のサムネイル＆公開キットを生成してください：
- 承認済みの画風に合う、横長 16:9 のサムネイル画像 1 枚
- YouTube タイトル 5 案
- 説明文、関連タグ、根拠がある場合は確認済みタイムスタンプ
- 固定コメント用の、反応を引き出す質問 1 件
- 未確認項目を明記した公開前チェックリスト
```

*画像生成には利用可能なツールと必要な費用承認が必要です。利用できない場合は制約を説明し、テキスト部分を先に納品します。承認済み脚本から先に依頼した場合は下書きとし、最終動画に依存する確認は保留します。画像をダウンロードし、文章を YouTube Studio や TikTok に必要に応じてコピーしてください。自動アップロード・公開は行いません。*

## ❓ よくある質問

### Q1. 本当に100%無料ですか？ 隠れた料金はありますか？

はい。Stickman Video Director は MIT ライセンスの100%無料・オープンソースプロジェクトです。個人利用にも商用プロジェクトにも自由に使えます。月額30〜60ドルを請求する独自の SaaS プラットフォームとは異なり、本プロジェクトにサブスク料金はありません。接続するモデルに応じて、Google Gemini、Claude、ElevenLabs などの外部 API の利用料金だけをご自身で支払います。

<!-- readme:platforms -->

### Q2. キャラクターの一貫性を保つにはどうすればよいですか？

**B · 全自動モード**：コードで制作を進めるワークフローです。動画制作の前にキャラクターの画像素材を生成し、各シーンで再利用するため、外見の一貫性は比較的安定します。

**A · 監督モード**：主にテキストから動画を生成します。髪型や服装などが複雑で、文章だけでは安定して再現しにくい場合は、棒人間キャラクターの参照画像を1枚追加し、後続のクリップでも使い続けると、より安定した結果が得られます。

### Q3. どのツールを使えばよいですか？画像生成モデルの指定は必要ですか？

**作例にできるだけ近い仕上がりを目指すなら、Codex をおすすめします。** B モードの作例は私が Codex で制作・テストしており、自分でコードを書く必要はありません。他の Agent にも Skill をインストールできますが、モデル、ツール設定、実行方法によって仕上がりが異なる場合があります。

私の制作例では GPT 内蔵の画像生成モデルを使い、別途 API は設定していません。他のエージェントでは、その環境で使える画像生成ツールを利用してください。B5 の実在人物や複雑なキャラクターには、生成済み、または確認済みの画像素材が必要です。コードで描いた代用の顔は使いません。音声名は制作例のクレジットであり、サービスの指定ではありません。必要ならエージェントに希望のサービスを設定してもらい、短いサンプルで確認してから全編に進みましょう。スタイルのプリセットは初期設定であり、制限ではありません。フォント、文字の演出、動画の言語を変えたいときは、エージェントに希望を伝えてレイアウトを調整してもらえます。

### Q4. 台本がなくても動画を作れますか？

はい。大まかなアイデア、ふと思いついたこと、ニュースのリンク、ブログ記事全文を貼り付けるだけでも始められます。AI ディレクターが中心となる対立を抽出し、引きつける3秒のフックを作り、題材・目標の長さ・選んだスタイルに合わせて物語とカットを構成します。笑いの間やナレーションの指示も加えます。

### Q5. 退屈さを避け、視聴者が見続ける動画にする仕組みは？

一般的な AI ツールは文章をそのまま絵にするだけです。Stickman Video Director は本格的な**視覚的ストーリーテリングの心理学**を活用します：

- **3秒のフック**：最初の一文を、すぐに伝わる視覚的な矛盾や好奇心を刺激する謎に変え、スクロールを止めます。
- **視覚的な比喩**：退屈な抽象概念を視覚的なギャグに変えます。不安を縮んでいくハムスターの回し車で、燃え尽きを残量1%のバッテリーで表現する、といった方法です。
- **テンポと笑いの間**：構造化された間、リアクションショット、効果音の指示（SFX）を挿入し、Casually Explained のようなクリエイターの笑いのテンポを再現します。

### Q6. YouTube や TikTok で収益化できますか？

はい、できます。顔出しなしのクリエイターが気にするのは、YouTube の「Reused Content（再利用されたコンテンツ）」や低労力の AI コンテンツに対する収益化停止ポリシーです。Stickman Video Director は独自のストーリー展開、語りのテンポ、オリジナルの画面演出を作るため、出力は完全にオリジナルです。数百のチャンネルが YouTube Partner Program（YPP）で棒人間の物語動画を収益化しています。

### Q7. プログラミングの知識や高価な GPU は必要ですか？

いいえ。ハイエンドの RTX グラフィックカードも、プログラミングの知識も不要です。

- **A · Model Engine** は通常のチャットで絵コンテとプロンプトを受け取るか、必要なツールを備えた Agent に生成・編集まで任せられます。動画クリップは利用する動画プラットフォームで生成します。
- **B · Code Engine** は Codex、Claude Code、Cursor などの Agent に自然な言葉で依頼できます。Agent がコードを作成・実行し、ローカルでレンダリングします。素材生成には設定した画像生成・音声サービスを使います。
