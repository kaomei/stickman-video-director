# Stickman Video Director

### どんなアイデアも、動き続ける1分間の棒人間動画へ。

ひとつの Codex Skill が、素材となる文章を、確認可能な英語ナレーション、映像主導のディレクタープラン、そして6本の実制作向け Gemini Omni Flash プロンプトへ変換します。

## 台本があるだけでは、まだ動画ではありません

良いアイデアでも、ひとりの人物、ひとつの背景、そして10秒間ほとんど変化しない平坦なアニメーションになることがあります。1分間を演出するには、フック、説明のテンポ、内容に合う視覚的メタファー、カメラワーク、シーン接続、さらに別々の生成をまたぐ一貫性まで設計する必要があります。

**Stickman Video Director は、生成クレジットを使う前に、その制作判断を整理します。**

## ショート動画クリエイターに役立つ理由

| 強み | 得られるもの |
|---|---|
| **強いストーリー構成** | 中心となる意味を保ちながら、素材を鋭い導入、段階的な説明、終盤のコールバックへ再構成します。 |
| **明確な承認ポイント** | 最終プロンプトの前に、読みやすい6シーンのディレクタープランを提示。修正コストが低い段階で物語を調整できます。 |
| **密度が高く、意味のある動き** | 各クリップに3つの時間ビートを設計し、視覚的メタファー、環境変化、カメラ移動、文字演出、人物同士の反応、トランジション、BGM、SFXを組み込みます。 |
| **制作条件を確実にロック** | 人物、線幅、配色、声、台詞、音、トランジション、ネガティブ条件を、各独立プロンプト内で繰り返します。 |
| **画面比率に合わせた演出** | `9:16`、`16:9`、`1:1` ごとに構図、カメラ経路、文字位置を再設計し、比率ラベルだけを置き換えません。 |
| **制御できる高コントラスト** | 白背景・黒人物、黒背景・白人物に加え、最大3色の高彩度アクセントを利用できます。 |
| **素材への忠実性** | 根拠のない事実、統計、引用、製品訴求を追加しません。 |

API や MCP への依存はありません。Skill をインストールして呼び出し、会話形式のガイドに沿って進めるだけです。

## 同じアイデアを、画面に合わせて再構成

| 比率 | 向いている用途 | 演出の重点 |
|---|---|---|
| `9:16` | YouTube Shorts、TikTok、Instagram Reels | 縦方向の奥行き、中央の強いシルエット、積み重なる展開、モバイルで読みやすい文字 |
| `16:9` | YouTube 解説、教育動画、ビジュアルエッセイ | 横方向の配置、左右のカメラ移動、分割比較、広いネガティブスペース |
| `1:1` | ソーシャルフィード、短いプロダクトストーリー | 強い中央構図、放射状の動き、読みやすい周辺余白 |

## 貼る → 選ぶ → 承認する → 生成する → つなぐ

1. **貼る：**文章、メモ、記事、またはテーマだけでも入力できます。
2. **選ぶ：** `16:9`、`9:16`、`1:1` から比率を選び、ライトまたはダークテーマを指定します。
3. **承認する：**英語VO、参考訳、映像、カメラ、トランジション、BGM、SFXを含む詳細なディレクタープランを確認します。
4. **生成する：**現在の提案が承認された後、独立して使える6本の Gemini Omni Flash プロンプトを受け取ります。
5. **つなぐ：**約10秒の6クリップを、まとまりのある1分動画に編集します。

比率、テーマ、ナレーション、シーン構成、配色、声、トーンはいつでも変更可能です。全体設定を変えると提案段階に戻り、再承認を求めます。

## 受け取れるもの

- クリエイター向けの英語タイトル、中心メッセージ、フック、トーン、配色、声、音楽方針
- 約1分に収まる **130〜150語の英語ナレーション**
- 2〜3秒ごとに明確な変化がある、互いに異なる6つの絵コンテシーン
- 正確な英語台詞と参考翻訳
- 時間ビートとネガティブ条件を含む6本の独立 Gemini Omni Flash プロンプト
- クリップ間をつなぎやすくする、対応した終わり方と始まり方
- BGM、効果音、一貫性、最終編集のガイド

## インストール

リポジトリをクローンします。

```bash
git clone https://github.com/kaomei/stickman-video-director.git
cd stickman-video-director
```

インストール可能な Skill フォルダを Codex の skills ディレクトリへコピーします。

```bash
cp -R skills/directing-stickman-videos "${CODEX_HOME:-$HOME/.codex}/skills/"
```

Codex を再起動し、Skill を利用可能な一覧に表示させます。その後、呼び出して素材を貼り付けます。

```text
$directing-stickman-videos
```

## 修正しやすく、生成上の差異にも正直

- **承認は必ず明示的に行います。** 現在の提案を承認するまで Phase B へ進みません。
- **全体変更では再構成します。** 新しい比率やテーマは、文字列を機械的に置換するのではなく演出から組み直します。
- **各プロンプトは独立しています。** 単独生成に必要な重要条件を毎回含めます。
- **意味の根拠を守ります。** 構成や伝え方は強化しても、根拠のない主張は追加しません。
- **音声には差が出る場合があります。** 個別生成では声や音楽が少し変わることがあります。最大限の一貫性が必要な場合は、各クリップの同期SFXを残し、編集時に連続した外部VOとBGMを加えてください。
