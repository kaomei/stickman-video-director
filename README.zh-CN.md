## 🎬 两种视频制作模式：Model Engine vs Code Engine

**同一个火柴人导演，两种画面制作路线**：A 模式用视频模型生成连贯镜头，B 模式用代码驱动素材做分层动画。两者均支持 Agent 全自动制作到成片，并严格按对应画风的规范交付。

给一个想法、一篇文章、网页链接或完整脚本，即可开始制作。两种模式均支持短视频与长篇内容，可按发布平台选择 `16:9` 横屏或 `9:16` 竖屏，并按需求与画风标准配置字幕、旁白配音、背景音乐和音效。

## 🧭 开始使用

<strong>想尽可能接近展示样片，建议优先使用 Codex、Claude Code 等编程能力较强的 AI 工具。</strong>

也可安装到其他具备文件读写与终端执行能力的 Agent，但模型能力、工具配置与执行方式不同，最终效果可能有所差异。

### Step 1：安装 Skill

首次使用会先检查所需配置，缺什么、怎么补都会逐步说明。把以下内容发送给你的 AI 助手：

```text
帮我安装这个 Skill:
https://github.com/kaomei/stickman-video-director

安装成功后读取 SKILL.md，并告诉我你已就绪。
```

### Step 2：选择画风和模式，一句话开始创作

选好喜欢的「[A 模式](#a-styles)」或「[B 模式](#b-styles)」画风，再复制下方对应的提示词，换成自己的需求后发给 AI 助手：

<a id="director-start"></a>

### A · Model Engine

```text
使用模型引擎（A 模式），把下面的话题/文案做成火柴人视频：
[填写话题、粘贴文案，或直接描述你的想法]

要求：横屏 16:9，采用风格 A3「史前洞穴风」，先做 30 秒。

先为我提供故事架构、声音方向与分镜方案；
我确认通过后，再提供独立可用的逐段视频生成提示词。
```

- **出片流程：** 分镜确认后，可自行手动生成，也可让 Agent 通过内置浏览器操作（先用低分辨率试片，满意后再连续制作并剪辑成片）。
- **推荐平台：** 推荐使用 Google Flow，便于接近样片效果；首次制作可参考 [X 详细教程](https://x.com/CrazyKaomei/status/2102311241046008268)。

<a id="autopilot-start"></a>

### B · Code Engine

```text
使用代码引擎（B 模式），把下面的话题/文章做成一条有吸引力的火柴人视频：
[粘贴长文、新闻、链接，或描述选题需求]

要求：横屏 16:9，时长 8 分钟，采用风格 B1「极简线稿风」，配齐旁白、字幕和音效。

先检查本地生图与合成环境，为我出具完整脚本与前 20 秒有声样片；
确认通过后，自动完成全片素材准备、代码编写与本地渲染，直接交付完整视频。
```

- **出片流程：** 确认脚本和 20 秒有声样片后，Agent 会按所选画风自动完成素材、动画、字幕与声音制作，在本地渲染整片并提供预览。
- **局部微调：** 成片后若画面或声音不满意，可让 AI 只微调对应片段，保留已确认的部分。

### Step 3：一键生成封面与发布文案

确认成片满意后，可继续制作[封面与发布工具包](#thumbnail-publishing-kit)，把这句话发给 AI 即可：

```text
为刚才的视频生成封面与发布文案，沿用已确认的画风。
```

AI 将为你一键生成匹配画风的封面图、视频标题、简介和置顶评论文案，无需切换模式或重新配置。

### A1：经典黑白风

一个圆头、几根线条，也能把复杂道理讲得让人会心一笑。黑白留白让每个动作和视觉比喻更醒目：焦虑可以是一座牢笼，注意力也可以是一格快要见底的电量。

- **视觉亮点**：白底版清爽轻快，黑底版更有悬念；少量亮色点出关键，画面干净，信息不打架。
- **适合内容**：科学常识、心理成长、自我管理、商业拆解，以及需要“换个比喻就懂了”的概念讲解。

### 工具包包含：

- **封面图片**: 1 张匹配已确认角色、画风、配色与核心冲突的 16:9 横版封面。有可用生图工具且所需费用获准后，直接生成图片。
- **5 个高点击率标题方案**: 兼顾搜索意图、好奇心缺口与广泛的观众吸引力。
- **YouTube Studio 简介与 SEO**: 包含主题摘要、相关标签，以及有最终成片或已核实时间轴支持的时间戳。
- **置顶评论互动钩子**: 1 个与视频相关、邀请观众真实交流的问题。
- **发布前检查清单**: 核对手机端安全区、对比度、内容准确性和素材权利审核状态，不保证通过 Content-ID 或获得平台变现资格。

### 如何触发：

你确认成片满意后，AI 助手会询问是否需要这个可选收尾包。同意即可继续，也可以跳过，不影响视频交付，无需复制提示词。你也可以直接说：

```text
为这个视频生成封面与发布工具包：
- 1 张匹配已确认画风的 16:9 横版封面图
- 5 个 YouTube 标题方案
- 简介、相关标签，以及有依据时提供的已核实时间戳
- 1 个用于置顶评论的互动问题
- 发布前检查清单，明确标注待核对项
```

*生图需要可用工具及必要的费用授权；工具不可用时，AI 助手会说明缺口，并先交付文字包。也可以在脚本确认后提前请求草稿，但依赖最终成片的检查仍会标为待核对。下载封面、按需将文案复制到 YouTube Studio 或 TikTok；不会自动上传或发布。*

## ❓ 常见问题解答 (FAQ)

### Q1. 这真的是 100% 免费的吗？有没有隐藏收费？

是的。Stickman Video Director 采用 MIT 开源协议，100% 完全免费且开源，你可以自由用于个人创作或商业变现。不同于传统每月收取 $30–$60 昂贵月费的商业软件，本项目没有任何订阅费。你只需根据自己选择调用的第三方大模型服务（如 Google Gemini、Claude 或 ElevenLabs）按需支付官方 API 费用。

<!-- readme:platforms -->

### Q2. 我该怎么保持角色的一致性？

**B · Code Engine（代码引擎）**：采用代码驱动的制作流程，在制作视频前会先生成人物素材图，并在不同场景中复用，因此人物一致性相对稳定。

**A · Model Engine（模型引擎）**：主要依赖文生视频。如果人物的发型、服饰等特征比较复杂，难以仅靠文字稳定复现，建议加一张火柴人角色参考图，并在后续片段中持续使用，让效果更稳定。

### Q3. 推荐用什么工具？必须用指定的生图模型吗？

如果想尽量接近展示样片，**A 模式推荐用 Google Flow 生成视频片段，B 模式推荐用 Codex 制作成片。** B 模式的展示样片均由 Codex 制作，你可以用自然语言描述需求，由 Agent 编写代码并在本地渲染。

**生图模型可以自行选择。** B 模式样片所需的图片素材使用 Codex 内置生图工具制作，无需另接生图 API。也可以用 Claude Code 等具备文件读写和终端执行能力的 Agent，搭配你已配置的生图和配音工具。建议先做一段有声样片，确认画风、字幕和声音后再制作全片。

### Q4. 如果我手里没有写好的现成剧本，能直接做视频吗？

可以。你可以直接扔给 AI 导演一段粗糙的想法、一个新闻链接、甚至一整篇公众号长文。AI 导演会自动提炼核心戏剧冲突，写出前 3 秒爆款黄金钩子，并根据主题、目标时长和所选画风安排故事与分镜，加入幽默节奏与台词断句。

### Q5. 它是如何确保视频具有高完播率、有梗且不枯燥的？

普通 AI 工具只会机械地把文字直译成画面，导致视频像催眠 PPT。Stickman Video Director 植入了专业的**视觉叙事心理学**：

- **黄金 3 秒钩子**：将开篇第一句话重构为视觉反差或悬念冲突，瞬间抓住注意力防止观众划走；
- **爆款视觉隐喻**：把枯燥抽象的概念转化为具象的搞笑视觉梗（例如把“精神内耗”具象化为一个疯狂自转的仓鼠轮，把“被掏空”具象化为头顶仅剩 1% 的低电量进度条）；
- **卡点与节奏留白**：内置情绪铺垫、反转神表情与音效提示点（SFX），完美还原 Casually Explained 等顶流创作者的幽默节奏。

### Q6. 生成的视频可以在 YouTube 和 TikTok 上开通收益变现吗？

完全可以。无脸号创作者最担心被平台判定为“搬运重复内容（Reused Content）”或“低质 AI 垃圾”导致无法获利。由于本项目生成的是具有高度原创叙事节奏、独特视觉分镜和有针对性撰写的故事脚本，成片完全属于高价值原创内容，符合 YouTube 创作者收益计划（YPP）与 TikTok 创作者基金的变现标准。

### Q7. 我需要懂编程或者拥有昂贵的高性能显卡吗？

不需要自己写代码，也不必专门购买高端显卡。A 模式可使用在线视频平台；B 模式由 Agent 编写代码并在本地渲染，制作速度会受电脑性能影响，但不是决定性因素。
