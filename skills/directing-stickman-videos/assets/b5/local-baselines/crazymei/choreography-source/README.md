# Choreography study source — both native layouts

These are unchanged user-authored scene sources from the existing CrazyMei portable templates, copied for local **reading**, not a runnable B5 renderer or a new generation path. The HTML uses its original host framework/global timeline and shared assets; those runtime dependencies are intentionally not duplicated. Do not point the B5 CLI at these files or assume they are self-contained. Spider remains the executable B5 scaffold.

Compare the explicit pose/prop/contact/effect keys in the four scenes and their different native coordinates in `16x9/` and `9x16/`. Learn the state-changing mechanism, timing asymmetry, contact ownership and independent secondary motion; reauthor these ideas for the new story using B5's renderer. Template code is evidence of implementation, not proof that a fresh portrait or story has passed continuous audiovisual review.

No raw narration, music or SFX library is included. User account/branding, blue rabbit host and script-specific text in this historical source are not B5 defaults. Preserve the finished reference's provenance and credits.
