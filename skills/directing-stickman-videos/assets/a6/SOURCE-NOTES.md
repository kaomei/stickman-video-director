# A6 reference files

These three files are original illustrations from this project's A6 production work. They are not screenshots downloaded from another creator. The overall drawing inspiration is YouTube [@IfverseTales](https://www.youtube.com/@IfverseTales); the channel is not an endorser of this Skill. The user-supplied growth figure (60K subscribers in three weeks) belongs to the presentation copy, not an independently verified performance promise.

- [Apartment style example](apartment-style-example.png): main portrait example from the accepted V4 film project. Inspect head/neck connection, small cream facial marks, black hands/legs, amber rim light, deep plum shadows and illustrated setting. Film-level acceptance does not mean every source still was separately approved.
- [Cafe face and light](cafe-face-and-light.jpg): supporting production-test still for face, near-field hands/props and lighting.
- [Shop full body](shop-full-body.jpg): supporting production-test still for silhouette, neck/body connection and foot contact.

The [manifest](reference-manifest.json) records exact dimensions, hashes and provenance. Paths are relative to the Skill root; no author's local workspace or logged-in project URL is required. These files contain no default creator watermark.

Use them as **style references** for a new story. The red-orange hoodie, cafe, shop and apartment are sample content, not mandatory A6 subject matter. Freeze a new story's approved cast, wardrobe and prop states separately. A character sheet is an identity reference; a single composed shot is a video first frame. Do not use one as the other merely because a provider accepts an image.

Follow [the prompt/reference contract](../../references/a6-reference-prompts.md). Resource integrity checks cannot establish visual fidelity, provider access or new-story user approval.
