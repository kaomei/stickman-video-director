Use the [portrait production and review rules](../../../references/b7-native-portrait.md): native scene rearrangement, unchanged pixel identity/font size, integer nearest-neighbor scaling, semantic speech timing, centered captions targeting 60% and never exceeding 65% of frame width including shadow. The longest accepted cue is 110/180 pixels (61.1%), with 35 pixels of whitespace on each side. Sample coordinates and timings are examples, not a universal template.

This approval covers this ten-second layout/caption example only.
