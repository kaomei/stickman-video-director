# B 模式声音素材库 / B audio library

已附带 774 个音效/声音转场、31 首背景音乐，另有 85 条短音乐句。可离线搜索、按 B1–B9 画风/剧情动作推荐并按需导出，无需账户或付费调用。

音效为 730 个 SFX + 44 个声音转场。85 条短音乐句不计入音效或完整配乐。编号变体是不同录音，不表示同样数量的剧情概念。

完整使用方法见 [声音库说明](../../references/b-audio-library.md)，逐项许可见 [catalog.json](catalog.json)，需署名的音乐及音效见 [CREDITS.md](CREDITS.md)。CC0 无强制署名；CC BY 3.0/4.0 需保留指定署名、许可链接与实际改动说明。素材商用/修改/再分发按各项许可执行。

没有独立统计当前热门榜单；以熟悉的喜剧配乐和适合故事的声音用途策展，禁止将每个文件标成“爆款音效”。没有把电影/游戏片段或来源不明梗音混入。
