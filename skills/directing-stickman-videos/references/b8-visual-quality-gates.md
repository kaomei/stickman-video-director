# B8 默认视觉检查：画风、构图、手臂方向与空间运动

选 B8 自动执行，不等用户逐项提醒。此规范同时用于新片和局部改稿；复用有效批准，只检查受影响范围。使用[已认可标准](b8-approved-standard.md)中的真实横屏和竖屏参考；技术成功不能代替看图、看运动或用户认可。

以[已确认样片反推的制作标准](b8-approved-standard.md#从已确认样片反推制作标准)为比较依据。检查用于在当前作品中找出并修复偏差；已经确认的标准直接生效，不因尚无额外测试片而搁置，也不增加用户审批阶段。

## 提案和绘图前

- **共同画风。** 全体可辨认角色与同一 B8 参考并排，检查轮廓线重、头身关系、面部和手部简化程度、明暗与纹理。每个人保留自己的身份、肤色、服饰；同一角色跨景别保持比例，不能近景突然长出写实手。绘图任务带共同参考、该角色身份和完整姿势。
- **按目标画幅设计。** 导演板标明每镜是全身、中景、反应近景或接触特写，以及必须看见的头、脚、手、接触对象和结果。9:16 原生安排人物纵深、大小、上下留白和字幕安全区；横屏居中裁切、缩放或加背景不能补出未画出的身体。全身镜的原素材须实际画全，缺下半身先补完整人物 cel，不能拉长衣服或代码补腿。接触特写可以有意留前臂在画外，不强制所有镜头全身；裁切须服务信息，不能无意切掉半个人或隐藏错误连接。
- **身体左右与画面左右分开。** 在关键动作说明中注明使用角色自己的哪只手、手从哪里进入、肘/前臂向身体哪侧回接、握点/支撑点、掌心/拇指朝向以及前后遮挡。跟全身角色并排检查。不能只因一只孤立的手画得自然就通过，也不能直接镜像带有角色/道具不对称特征的素材。没有自然连接就重画完整动作单元，或按已批准方案切接触细节→结果→反应。
- **空间运动先说明目的。** 每镜写固定或移动机位、运动主体、同平面层、前后景深度和停点。相机运动对同一世界关系使用共同变换；脚底、接触阴影、落地树枝、桌面与被支撑道具保持配准。景深差速须有实际层次依据；不能单独滑动背景假装推镜。树叶已画在背景里时，横移底图不是风吹树叶；要风动须有独立局部层/状态和合理支点。不需要动的镜头允许停稳。

## 关键姿势与实际编码成片

1. **构图检查**：逐镜看目标画幅首/中/尾及最大位移处。全身镜头顶至脚底完整、无贴边或字幕遮挡；近景保留能读懂的接触位置。两种比例分别检查，横屏通过不传给竖屏。
2. **方向检查**：看接近、首次接触、变化、结果、反应与切点前后；核对角色自身左右、腕肘回接、袖口/肤色、持物、桌后遮挡和跨镜方向。不能只看首尾静帧。
3. **背景运动检查**：看完整运动路径和机位收稳后的区间，重点比较脚底/地面、手/物、物/支撑面和背景树叶。检查脚滑、漂浮、背景与地面错速、无动机横漂、整个人绕脚旋转、停点后继续飘；静止本身不是失败。V5 开头修正的是独立底图横移，不能把“所有背景禁止运动”作为结论。
4. **全角色画风复核**：实际编码画面中的全部角色、近景手及新角度与共同人物板并排；修正错误后复查受影响镜头。原画通过不代表合成缩放、翻转和遮挡仍然正确。

检查优先后台解码、合适尺寸拼板和必要原帧，再看正常速度运动。使用可用的聊天内/内置预览；不要为检查擅自抢占用户桌面或操作原生播放器。工具不能实际播放/听音时如实保持相应项 pending，抽帧不冒充完整回放。

## 默认导出的检查记录

`proposal`、`keyposes`、`preview`、`render` 的报告自动带 `quality_review`。提案检查共同画风和目标画幅构图；关键姿势增加手臂方向；实际视频再增加背景/接触空间运动。每镜独立列项，初始全部 `pending`，不会因为导出成功自动变成合格。

代理实际看过后填写每项 `status: accepted`、`reviewer`、具体 `notes`（镜号/时间、预期与看到的结果）和 `evidence: [{path, sha256}]`。证据使用该报告 `artifacts` 内已绑定的真实板图或视频；额外抽帧/拼板须先加入 artifacts 并核实指纹。视频阶段的逐镜构图、方向、空间运动还须引用实际 MP4，不能只引用生成前草图。无可见手臂等不适用项可写 `not_applicable`，仍需说明原因与证据；固定镜头应记录为空间关系稳定，不能笼统全部填 N/A。任何 failed/pending 项先修；代理内部审查与用户批准分别记录。

现有 `approve` 在记录新批准前核对这些审查记录和证据；不新增用户审批阶段，不撤销未改变镜头的有效历史批准。新批准绑定独立的已审报告快照；继续补审原报告中的其他镜头不会撤销先前有效的局部批准。显式的视觉、技术或听音失败会阻止检查通过；pending 不补签为听审或用户认可。完成成片后，在交付前执行：

```sh
node scripts/autopilot.mjs validate /absolute/project --review /absolute/project/outputs/film-v1.report.json
```

此命令核对当前提案/镜头指纹、实际产物与已填写检查项，不会识别画面好坏。审查者不能为过门槛批量填 accepted。完整回放、实际听音与用户验收继续独立记录；未知不补签。代理填写和验证记录，不要求用户编辑 JSON。

## 默认字幕、音效和背景乐的完整性验收

选 B8 后自动执行[B1–B9 成片完整性门禁](b-delivery-completeness.md)，并完成本文件原有视觉验收。按本风格样片的字幕呈现、剧情音效和配乐方向制作；逐项核实它们实际进入最终 MP4。缺项、未查或工具不可用，均不能标记完整达标；字幕侧车、已下载音频和编码成功不能代替成片证据。保留原有手绘角色、接触姿态、语义字幕和场景声音，配乐贴合故事。用户明确豁免及叙事性局部静默按通用门禁留证，不把制作困难当作豁免。

```sh
node scripts/b-delivery-completeness.mjs init --style B8 --ratio 16:9 --media /absolute/candidate.mp4 --output /absolute/completeness-review.json
node scripts/b-delivery-completeness.mjs check /absolute/completeness-review.json
```

命令使用本次实际比例和输出路径；新记录默认全部未检查。机械门禁只核实证据完整性，画面效果和实际听感仍需如实审看、审听。既有样片批准和音乐许可结论保持各自原有范围。
