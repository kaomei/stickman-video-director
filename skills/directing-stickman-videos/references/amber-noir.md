## Shared story and visual preparation

1. Reuse the supplied topic/link/script, ratio, duration and narration language. If essential creative choices are missing, ask together; otherwise plan immediately. Thirty- and sixty-second stories use the same narrative planning process. Preserve the requested total runtime; never round it to an Omni ten-second multiple.
2. Produce the director's proposal: premise, hook, causal progression and payoff; exact narration; story-specific cast and visual reference plan; shot timeline; intended audio/captions; and proposed generation settings if relevant. A reaction or deliberate pause is valid acting. Do not force a discussion ending or pack decorative devices into every shot.
3. Obtain proposal approval, then deliver the independently usable prompt package: shot-specific first-frame and motion prompts, actual reference files and their input roles, intended settings, separate narration and finishing notes. Offer optional generation only after this handoff unless that continuation is already explicitly requested and authorized. Reuse approved narration and design; changes to those or the global brief require scoped reapproval, not automatic regeneration of unrelated accepted shots.
4. Before claiming that references are missing, inspect the bundled [A6 reference manifest](../assets/a6/reference-manifest.json), open its actual images and read [reference use and complete prompts](a6-reference-prompts.md). Show the suitable available example and explain its role: the accepted-film style example is not automatically the new story's approved cast or opening. Use the bundled images for drawing/light grammar, and include the story-specific cast and shot composition in the proposal confirmation. Supply fully expanded shot-specific first-frame prompts; never deliver unresolved style/cast/world lock placeholders. If files really are absent or unreadable, identify the exact missing file and recover the reference pack or arrange an approved reference-image step; never fabricate a link or substitute a multi-panel sheet as the shot opening. Do not require a new style-reference generation when a suitable image already exists.
5. Plan narrative acts separately from generated clips. Verify the selected model’s currently supported durations before allocating clips; the accepted Veo sample used clips up to 8 seconds, which is provenance rather than a universal A6 limit. Allocate editorial time by story and actual speech, not a fixed six-scene or three-clip recipe. Prepare handles/cuts without speeding narration to fit.

Drawing grammar: compact matte-black round heads, connected short black necks, small cream-white eye marks and a compact line mouth; simplified black hands and limbs with a readable silhouette. Use angular illustrated contours, restrained cel shading, amber illumination and deep plum shadows in layered full-color settings. Keep dimensional lighting without turning the cast into glossy 3D toys or realistic people. The red-orange hood-down hoodie belongs to the current sample character, not every A6 story. Freeze the approved cast's proportions, wardrobe, palette and props within each film; vary locations according to the story rather than reusing one background.

For each shot record: editorial time, location and camera, visible cast, incoming prop/pose state, one clear main action and reaction, outgoing state, first-frame reference, separate VO interval, SFX cues and planned cut. Keep hand/prop contact and screen direction legible. For difficult actions, test a representative shot first within the authorized budget.

Run `python3 scripts/a6_reference_check.py` from the installed Skill directory to check the bundled resource integrity. Before image handoff/submission, record and check the reference plan as described in [the A6 prompt contract](a6-reference-prompts.md). This is a resource/structure gate, not a visual-quality verdict. Read the images and inspect actual generated results too. If the current Agent cannot read images, attach reference inputs or generate images, state the specific unavailable capability and give the complete prompt plus the actual reference files for a user-assisted handoff; do not infer that the package has no references or call that handoff a finished film. Selecting A6 or passing this check never authorizes a paid call.

- Export valid clips and assemble locally with the shared finishing rules below. If browser control or exporting is unavailable, report the specific limitation and offer user-assisted operation. Do not silently switch providers or call a prompt package a finished film.
