## 全角色同一画风，身份各不相同

| 全片固定的画风语法 | 随角色与故事确定的身份 |
|---|---|
| 有情绪的二维卡通面部；清楚而克制的五官与表情 | 脸型、年龄、性别、体态、当下情绪 |
| 深棕轮廓、相近线重与细节密度；成组明暗、绘画纹理的赛璐璐色块 | 肤色、发型/胡须、冠饰与其他识别特征 |
| 简化细线四肢、紧凑圆手、自然窄腕；脸和手属于同一写实程度 | 肢体自身颜色、服装覆盖、袖长、袖口、鞋与配饰 |
| 有方向的光线、浓郁而有层次的环境；人物与道具轮廓清楚 | 场景、时代、材料、故事所需的色彩与明暗 |

主角、配角、女性、少年、老人和可辨识群像都执行左栏。不把“同风格”误解为全员迈达斯、全员浅肤色、同一张脸或同款长袍；也不因换身份就改成写实手掌、另一种线重或另一种卡通比例。宙斯已有眼睛等身份契约继续保留，不强行套迈达斯的五官。

每个新角色的生成/绘制指令都带上**共同画风锚 + 完整身份锚 + 当前姿势/视角**，并实际附上可用的已认可画风参考。不要只写“同上”“保持一致”，也不把新角色从整片画风隔离生成。可复用共同锚：

> Expressive 2D cartoon character in the attached approved B8 drawing family: dark-brown contours, grouped cel shading with painterly texture, thin simplified limbs, compact rounded cartoon hands and naturally narrow wrists. Match the reference's drawing density, stylization and lighting grammar across all characters. Preserve the separately specified identity, skin tone, hair, costume and accessories; use the requested complete pose and view.

以上是画风锚，不覆盖角色契约，也不代替真实附图。工具无法接收参考时记录限制，先为当前任务所需角色或姿势出静帧作内部并排核对，不能声称已自动锁定一致性；无需另做动画样片或重批固定画风。

提案板包含 **cast/style board**：全部出场角色与已认可参照并排，再放必要的全身、表情近景、手掌—手腕—前臂。逐人合格还不够，必须检查放在一起的线重、明暗、面部与手部简化程度。同一角色的全身与近景另核头身比例、冠饰、手掌大小和服装；均匀缩放只能调整画面大小，不能修正原画内部比例差异。已确认角色直接复用；新角色单独修正，不无故重做整套。

将 `b8_style_lock` 保存在项目既有 checkpoint：基准版本/指纹、共同画风锚、cast/style board 路径与指纹、全部出场角色 ID 及其身份/素材契约、逐角色与同板审阅结果、实际批准范围。缺失或失败的角色保持 pending；新增角色、换画风或改部位素材后复查受影响项，不能仅有主角通过就推进整片。此记录与现有角色契约互相引用，不另建矛盾状态文件。

## 默认动作路线：先画准确姿势，再编排动画

1. 先按实际语音设计接近 → 接触 → 变化/结果 → 反应；注明角色身体自身的左/右手，以及其画面进入方向、掌心/拇指、握点、腕—前臂—肘回接身体哪侧、袖口、肤色与物体支撑。将局部姿势与全身参考并排检查，不能只看孤立手掌自然就通过。
2. 把**完整绘制的手掌—手腕—前臂或持物人物**作为动作单元。代码优先编排完整 cel 的有限位移/旋转、前后遮挡、姿势/表情替换、道具状态与局部材质变化。场景与人物按需要独立分层。
3. 不默认用 IK、代码拉长手臂、逐关节拼装或重复侧身伸一根手指补齐动作。没有自然姿势就补画；复杂动作可拆为“接触细节 → 明确结果 → 独立人物反应”。这是重新设计信息与表演，不能把同一成图裁切成多镜。
4. 在当前获授权制作的范围内查看中间帧和实际编码运动；复用有效既有短动画，缺少相应运动证据时仅制作受影响段的内部短测试。复杂关节动作只有在关键姿势及运动自然后才保留；错误先修素材或调度，不靠滤镜、遮挡、特效掩盖。批准准确关键姿势后再制作获授权动画，不无故重问已批部分。

## 目标画幅原生构图与共同空间

目标为 9:16 时，从导演提案、构图草图和准确姿势就按竖屏设计；不是把横屏直接居中裁切。每镜记录该比例下必须可见的动作、接触点与结果，以及全身、中景或近景的构图意图。全身镜保留头冠到双脚、脚底落地与字幕安全区；近景有明确取景理由，半身 cel 的平底不能露在画内形成悬浮断身。需要自然遮挡时使用空间成立的真实前景，不用遮条掩盖错误。检查首、中、尾与最大位移处，横屏批准不自动传给竖屏。

人物、脚下地面、桌面与持物处于共同空间，按同一相机和有依据的纵深处理运动；分别核对脚底—地影、手—物、物—支撑面及背景的相对关系。查看完整路径和停稳段，退回脚滑、漂浮、同平面错速、独立底图无动机横移或整人绕脚旋转。固定镜头与安静反应可以成立，不为增加动感让所有层持续飘动；V5 的具体底图横移修正不等于禁止有动机的背景视差。

逐镜执行[默认视觉检查](b8-visual-quality-gates.md)。`proposal`、`keyposes`、`preview`、`render` 报告自动附 `quality_review`，所需项目从 pending 开始；实际审阅者填写说明与绑定本报告产物 SHA-256 的证据，视频项目核对实际编码 MP4。现有 `approve` 在记录新批准前检查这些记录，pending/failed 先修；不新增用户审批阶段，不撤销未受影响的有效历史批准。交付前用现有 `validate PROJECT --review REPORT` 只读核对。记录检查不能识别画面好坏，也不等于用户认可。

## 丰富镜头与因果作为同一项设计

按故事选择环境建立、物体插镜、俯视接触、人物中近景、反应、远景后果等；改变信息、空间和主体关系，交替动静与尺度，有限运镜结束后停稳。新地点有地理或时间连接，同一地点也不能反复围绕同一桌子或同一侧面。不要机械照搬本片的 14 镜、时间码、树枝、宫殿或镜头顺序；故事没有换地点需要时不硬凑。

所有主要与附带接触都审：树枝是否已断落、桌子/帘子是否被碰到、谁拿着物体、间接接触是否传导、变化作用于什么完整对象、结果如何跨镜保留。界定依据来自本故事，不把迈达斯的金化规则变成所有 B8 故事的世界观。连续运镜保持共同空间变换；另画透视插镜以剪切连接，并核对物体身份与动作/材质状态。

## 交给用户前必须退回修正的情况

- 同片角色画风混杂；手明显比脸写实；近景改变角色肤色、衣袖或比例。
- 掌腕连接生硬、胳膊被拉长、额外肢体、持物不接触、物体跨镜换形/换手或无因复原。
- 手掌孤立看似自然，但手腕、肘向无法归属于同一角色；竖屏露出半身贴图平底、全身缺头缺脚，或脚与背景不在同一空间运动。
- 正文退回静图推拉、反复同一场景/构图却没有新信息、变化没有结果或人物反应。
- 规则只对旁白提到的物体生效，却忽视桌帘等附带接触。

先按实际基准审阅修正，再交用户；不能以“已渲染”“文件检查通过”代替视觉合格。保留已确认文案、原速完整配音和角色素材指纹；局改只动受影响部分。样片批准、后续范围、付费与发布继续按已有授权分别记录。

横屏试片的既有认可继续保留。本次 V5 正面反馈只针对当前这支 Midas 竖屏版本的画面；不扩大为 Kingdom 的认可、独立听审通过或发布许可。文件完整性与本机路由可以验证；新故事、多角色、长片及任何新比例/改稿仍须按受影响范围在实际作品中独立审阅，不补签未完成的回放、听审或用户验收。未来出现同类问题先按以上失败项修复，不再要求用户重述标准。
