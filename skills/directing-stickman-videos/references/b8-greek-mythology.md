# B8 · 希腊神画风

Locally installed, unpublished style module inside `directing-stickman-videos`, not another Skill installation. B7 remains Pixel Theater and is unchanged. Use this contract for B8 planning, code animation, revision and review. Selecting B8 also selects the [approved default standard and bundled visual references](b8-approved-standard.md) and [visual quality gates](b8-visual-quality-gates.md); inspect the actual landscape/portrait references before planning, without asking the user to choose this drawing style again. Read [Autopilot](autopilot.md), the [mode boundaries](mode-execution-boundaries.md) and [common production QA](autopilot-production-qa.md) as well.

Visual inspiration: [@HeyHistorically and the dated public channel data](b8-inspiration-source.md).

## Scope and reference lock

- **代码分层动画，不是视频生成。** 人物、场景和必要道具是独立素材，由代码编排镜头、遮挡、位置、表情与局部动作；不能把一张成图整体推拉当作分层完成。
- 视觉默认对齐已认可的 Midas R3 v1 样片：有情绪的二维卡通面部、深棕轮廓、成组明暗和绘画纹理、紧凑圆手与自然窄腕、简化线条四肢。主角、配角、群像共用同一套画风；肤色、年龄、脸型、发型/胡须、服饰与配饰按角色身份区分，不把迈达斯的浅暖肤色和造型套给所有人。保留浓郁的赛璐璐色块、清晰明暗分组和有方向的光线；背景可柔和，不能褪成低对比灰雾，也不能艳得压过人物。不要改成写实人体、普通 Q 版或全员同款宙斯长袍。
- 宙斯当前眼睛标准为黑眼形内一点小白点，沿用确认的眼睛素材，不自动改成彩色眼睛、空洞纯黑或统一愤怒眉。其他角色按各自身份与当下情绪表演，不复制宙斯面部模板。
- 按目标画幅原生构图。9:16 从提案和姿势阶段单独设计每镜可见动作、接触/结果与全身或近景意图，检查首中尾及最大位移；全身保留头冠、双脚、地面关系与字幕安全区，近景不得露出半身 cel 的平底。横屏批准不自动覆盖竖屏，不能用居中裁切代替构图审阅。实际竖屏参考为附包 Midas V5 与其开场/全身/手臂方向板。
- 开工先查项目 checkpoint、角色/场景清单、实际移动参考及已确认音轨。参考视频看色彩、笔触和时间中的表现，不能只凭一帧猜运动。本 Skill 已附带获认可试片、人物画风板与接触/逐镜参考，见默认标准；另含[可移植执行流程](b8-installed-workflow.md)、独立认可样片复现与新故事分层运行时。先核验基准包再查看实际图像/运动；缺少当前故事的角色、视角或渲染入口时明确记录，先完成不受影响的计划，不冒充已复现。
- 本地安装已支持 `doctor/init --style B8` 与专用 B8 制作命令；不代表新版已经公开发布。不得借此生成后续全片、付费重录、发布 GitHub 或改动 B7；授权按当前请求执行。

## 先审分镜导演提案板

新片及涉及场景、分镜、动作因果的改稿，先执行 [分镜导演提案板](b8-director-proposal-board.md)：锁定原文/完整配音和已确认人物 → 审查全段镜头、故事规则及附带接触 → 展示板图、关键姿势示意和待定项 → 用户明确确认该版本 → 准确关键姿势/必要动作测试 → 获授权动画。提案未经确认，不启动该范围的后续制作。角色好看、旧样片认可和技术检查通过均不等于新提案确认；续接时只沿用仍有效、范围明确的批准。

## B8 installed runtime

默认执行 [安装后制作流程](b8-installed-workflow.md)：`node scripts/autopilot.mjs doctor --style B8` → `init DIR --style B8`（仅新故事）→ 代理编排全段并导出 `proposal` → 展示实际导演/角色板并记录用户批准 → 绘制/复用自然完整姿势，导出 `keyposes` 并确认 → 获准区间 `preview` → 实际样片审核与后续范围授权 → `render`。这些命令直接分发至 B8 专用运行时，不把 B8 加进通用静图画面的风格列表。

已存在工程继续沿用实际 checkpoint 和有效素材/代码；不为安装测试重建用户工程。新故事入口自带画风参考、绘图任务、逐镜表、接触审计和批准指纹绑定。完整绘制的 cels、道具状态、局部材质与相机为实际执行对象；复杂动作先设计接触细节、结果与反应，不生成关节式胳膊。

`proposal`、`keyposes`、`preview`、`render` 报告自动导出逐镜 `quality_review`，所需项从 pending 开始，覆盖全角色共同画风、目标画幅构图、关键姿势/视频的身体左右与手臂方向，以及视频空间运动。按[视觉检查规范](b8-visual-quality-gates.md)实际查看后，记录审阅者、镜号/时间与具体说明、绑定报告 artifacts 的 SHA-256 证据；视频检查引用实际编码 MP4。现有 `approve` 检查记录后才写入新批准并冻结独立报告快照，pending/failed 先修，不新增用户审批阶段；后续补审原报告不撤销未改变范围的有效历史批准。交付前执行 `node scripts/autopilot.mjs validate PROJECT --review REPORT` 作只读终检。它核对文件、指纹和记录，并阻断显式 visual/technical/listening failed；不识别画面好坏，也不能将回放、听审或用户验收的 pending 改称通过。

`demo --style B8 --output ...` 可在不读原工程的情况下从附带素材重新渲染获认可 Midas 20 秒，沿用原完整声音 1x。它是具体样片复现，不能作为新故事、多角色或竖屏已验收的证据。新故事仍由代理按实际参考绘图和调度，不是套用 Midas 镜头/角色。

**证据绑定门槛：** 项目审查须清点实际执行的传递依赖闭包，包括动态导入、延迟加载的字体/素材、复用的源 MP4 和音轨；不能只列入口或任选几个祖先版本。将实际读取与保守保留的素材分别标注，不把“已保留”说成“已使用”。字幕须合并开场、正文及其他实际绘制分支，与已确认全文核对；只导出继承的正文字幕表不算完整。

使用 [B8 证据检查器](../scripts/check-b8-evidence.mjs)：`node scripts/check-b8-evidence.mjs --manifest <evidence-manifest.json> --qa <qa.json>`。证据清单使用检查器的 schema 1，记录 `style: B8`、成片与依赖的 SHA-256、覆盖完整时长的逐镜方向记录和完整字幕；它与 B8 project.json 制作参数分开。QA 必须绑定清单原始字节及实际编码媒体的 SHA-256，检查项须有可复查证据。检查器只核对已列文件和记录，不发现依赖、不执行渲染，也不证明观感、听感或任意新故事已经达到样片质量。不能用全为 true 的自填记录代替项目审查。

静帧/抽样技术检查、完整正常速度回放、实际听音和用户验收分开记录；缺失的验收保持 `pending`。仅在三项实际验收均有证据后使用 `--require-acceptance`，不能为让门槛通过而改状态。旧工程按固定时间切换遮挡顺序时，记录为时间编排例外并核对切换前后帧，不能写成已经验证空间触发；规范审查不自动授权重做已保留成片。

## 全段执行，不只做开头

同一标准覆盖**本次获授权的完整时长**，包括开头、正文、转折、反应和结尾。20 秒样片覆盖这 20 秒；样片认可不等于其余全片已制作、已验收或获准开工。后续获准扩展时，所有新增镜头同样执行，不能回退成配字幕的静图轮播；不能只精修开头或结尾，而让正文退回同轴静图推拉。

丰富度来自**信息变化、空间关系、素材/状态切换与节奏**，不是四肢动作数量。没有走路剧情就不做走路；移动可用整张角色 cel 的有限位移、轻微重心变化、视线、表情及衣发滞后，不强制两腿交替。也不让所有层永远飘动。严肃、史诗感需要停顿、尺度与后果，不靠持续抖动或特效堆砌。

## Per-shot ledger

制作前给授权范围内**每一镜**建一行，禁止只详细规划前几秒。表格或 JSON 均可；每行至少包含：

| 字段 | 要记录的决定 |
|---|---|
| `in / out / words` | 实际音轨区间、对应原文与语义节点；不能凭均分词数伪造对齐。 |
| `focus / information_change` | 看谁/什么；本镜前后观众新知道什么、关系或情绪如何改变。 |
| `assets / states` | 实际文件/身份、前后视角、表情与道具状态；素材切换或沿用的理由。 |
| `depth / occlusion` | 远景、中景、角色、近景挡层的空间关系、共同坐标/锚点、谁遮谁；穿越时记录遮挡顺序改变的空间触发条件。按镜头需要设层，不为凑数量拆层。 |
| `camera / motive / settle` | 起止构图、运动窗口、被揭示的主体/关系与尺度变化、何时停稳；固定镜头说明其叙事作用即可。 |
| 目标画幅构图与可见动作 | 当前比例下须读清的动作/接触/结果、全身或近景意图、头脚/贴图边界与字幕安全区；9:16 独立核对，不能只登记输出尺寸。 |
| 身体左右、握持与空间运动 | 区分身体自身左/右与画面左/右，记录掌心/拇指、腕肘归属、握点与遮挡；记录脚底/地影、手物、物体支撑及背景在完整路径和停点中的相对关系。 |
| `performance / continuity` | 因果触发、视线/表情、动作跨切、屏幕方向、道具归属及下一镜连接。 |
| `rules / contacts / state_link` | 故事规则的依据/待定边界；主要与附带接触、直接/间接关系、作用对象范围、变化起点/结果及跨镜状态。无规则剧情不虚构魔法；使用提案板的接触审计表。 |
| `audio / captions / review` | 复用音轨及事件时间、语义字幕、安全区、首中尾/密集条检查结果与失败时间点。 |

删掉某个移动/切换后信息和情绪仍完全一样，就重新判断它是否只是装饰。没有实际素材支持的视角、门后空间或剧情动作标为缺口，不能为了增加镜数偷偷编造。

## Layering and purposeful camera

1. **先有空间，再挑运动。** 建立人物、地面、建筑与远处环境的统一坐标。可以远景/云层/近景遮挡进入，再发现人物；也可以立即给关系清楚的构图。云散或超远景不是每条片必用片头。
   人物与脚下地面、桌面/持物按共同相机及有依据的纵深处理；脚底与阴影不得滑开，同平面背景不得错速或独立无动机横漂，停点后不得继续飘。检查整个路径，不只首尾。固定镜头和安静反应可以成立，不用整人绕脚旋转增加动感；Midas V5 修正特定底图横移不代表禁止所有背景视差。
2. **用遮挡揭示关系。** 岩石、柱、肩背等近层可较快经过，人物与远景差速变化，揭示门、废墟或另一人物。被揭示区域必须有完整底图；景深不是几张平面等速滑动，也不是把同一建筑画两次制造重影。
3. **每镜一个主导目标。** 镜头跟随动作、发现空间/对象或把注意交给接收者。记录有限起止位置，适度缓入缓出；信息读清后停稳。不要每镜固定推近、随机摇晃、在台词重点仍不停漂移，或围绕平面角色做虚假的 3D 环绕。
4. **动作引导相机，不是相机代演。** 例如先开始抬道具，再轻跟上升；切近景时动作轨迹继续。宣告后让接收者有先后、有差别地反应，而非全员同时晃头。保持视线、空间轴与人物/道具方向，必要越轴先交代新地理。
5. **保留读懂的时间。** 固定镜头、克制表演和短暂静止均可有目的；同时执行 B 通用的最长 2.5 秒主体信息停滞检查。这不是每 2.5/3 秒强制切镜，也不能用无意义摆动、字幕更换或整图缩放规避。

## Meaningful material and shot switching

- 随剧情改变信息承载者：宏观环境建立 → 相关建筑/道具插镜 → 人物关系 → 决定/动作 → 接收反应，可选其合适组合。不是固定顺序或每段必凑五类。
- 切换可以是新环境、不同视角 cel、前/后景主体、表情状态或有意义的构图关系；不等于每镜必须生新图。同一场景复用有利于连续性，但不同句子不能一直使用同一张脸的不同缩放。
- 远近景、群像/单人、主观越肩/客观全景形成有理由的节奏。动静交替，少量大运动与可读停点相配；短镜不闪过，长镜有主体进展。不要机械复制当前 20 秒的镜数和时间码。
- 保留原文因果与揭示顺序。未开启的门仍关闭；未出现的威胁不提前现身。史诗感不授权捏造历史/神话事实、提前兑现后段悬念或强塞恐怖结尾。
- 参考例（非模板）：远处云层揭出王座；王座转到其宣告者；近岩后发现封闭门；越过背肩读出三人位置；切到另一处废墟而非重复片头；动作内切近景；宣告后顺次读两人的反应。复用的是“信息/空间/因果”，不是宙斯剧情或固定镜数。

## 跨镜揭示与尺度变化（全段适用）

- **按信息推进，不按缩放凑镜头。** 一段可由相关细节引出动作，再揭示结果或更大空间；每次切换须增加可读信息。同轴推拉若没有新信息，不能冒充素材/镜头变化。细节、行动、空间尺度是可选的组织手段，不要求每段三镜，也不要求统一顺序；静态反应与有目的的停顿仍可成立。
- **分层各司其职。** 近层负责遮挡、经过或退场，中层承载角色与动作，远层交代目的地和规模；按透视与相机关系计算差速，而非所有层一起滑动。前景移开后，后方有完整空间可读；不得把同一建筑叠两次，或用亮光/黑洞代替未准备的场景。需要新环境或视角时先列素材缺口，不能用旧图无尽放大顶替。
- **穿越要保持地理连续。** 门、柱或岩缘经过镜头时，可让近层更快清屏、角色持续前进、远景逐渐展开。跨切保持人物投影位置、行进方向与动作阶段的连续性，允许有动机的景别变化；遮挡顺序随角色跨越空间平面而改变，不能仅到某秒就把人物突然提到最上层。前后镜的门框、开口与铰点必须配准。
- **预兆、触发、结果各有落点。** 例如门仍关闭时只给有限震动/落尘，实际开启与已确认的因果音效对齐，再让人物或镜头越过门槛；不提前泄露后方世界。相机揭示新空间后，应让观众读清尺度、人物处境与选择后果，再停稳；不在台词结束后继续无意义漂移。
- **已确认实践（非模板）：** 门缝预兆特写 → 独立门扇打开、人物穿越 → 近景建筑退场、冥界全景展开并收稳。后续正文、转折和结尾都沿用这种“信息递进 + 独立纵深 + 因果连续 + 有限运镜”的标准，不复制门、冥界、时间码或固定镜头顺序。

## Code and asset safeguards

### 角色部位与跨景别素材验收（先于动画）

- 每个角色建立 **body-region contract**：分别记录脸、头发/胡须、上臂、前臂、手掌、腿、鞋、衣服、袖长/袖口与配饰的材质、颜色、轮廓和连接点，并绑定已确认参考及素材指纹。白色简化面部不等于白色前臂或手套；不能把某个角色的黑色线条手臂强制套给所有角色。各角色保留自己的颜色与服装，但共用 B8 的四肢简化程度，不能据此改成写实人体。新角色先提出并核对具体设计，后续按该角色契约锁定；所有角色另须在同一张画风板上并排比较，不能只逐人通过。
- 新姿势、新表情及近景须与全身参考并排验收：袖口、肤色/线肢、冠饰、手掌大小、关节和服装边界一致，正常光照只允许有依据的明暗变化。不允许用暖色滤镜、遮挡、裁切或镜头运动掩盖白臂、错袖、额外肢体等原素材错误；发现后退回素材修正，不能带病进入动画。
- 每个关键手部动作明确角色自身哪只手、其画面进入方向、掌心/拇指、握点、腕—前臂—肘回接身体哪侧及遮挡；与该角色完整姿势并排，不能只审孤立的手掌或把画面左右当成身体左右。错误时重画完整接触单元，或使用已批准的接触细节→结果→反应；不能只镜像带非对称身份/道具的素材。所有角色还须同板检查线重、面手简化程度、明暗与头身比例；均匀缩放不等于修复原 cel 的内部比例差异。
- 使用项目内 `scripts/check-b8-character-contract.mjs --manifest <character-contract.json>` 检查 schema 1 的参考/素材 SHA-256、部位定义、必需验收项及逐素材实际审查记录；记录失败时须阻止通过。该检查器只能验证声明与文件完整性，不能自动识别人物部位颜色或替代人工图像审查，也不能凭自填 pass 宣称视觉合格。
- 同一道具维护一个身份及状态链：轮廓、切口/纹样、握点、持有者、位置和材质变化分别记录。远近景优先复用同一独立道具；必须另画视角时先并排核对。近景不得凭空加长袖、棕袖口，面包不得圆形变长条，酒杯不得换纹样。连续动作及动作内切中，道具从手中到地面/桌面须有放下或掉落的可读动作，不能靠切镜瞬移。经用户确认的明确时间省略可跳过转移过程，但须记录省略边界、最后可见状态及后镜状态依据；不能声称已展示转移，也不能用省略掩盖规则冲突。
- **默认绘制完整动作单元。** 先画自然的手掌—手腕—前臂接触姿势，再用完整 cel 的有限位移/旋转、姿势或表情替换以及物体材质变化组织动画；不默认使用 IK、代码伸长胳膊或逐关节拼接。缺姿势先补画，或设计“接触近景 → 结果 → 人物反应”；不靠裁切掩盖错误连接。确需关节表演时先核对关键姿势及实际运动，不以技术成功替代自然度。
- 每个接触点检查接近 → 接触/握持 → 状态改变 → 角色反应；不要求都用手指特写。按剧情选择全景、越肩、中景或物体细节，手掌/持物与脚底锚点须连续。动作内切前后保留同一道具归属与动作阶段，表情为当前信息反应，不能全程同一张张嘴脸。
- 同一连续运镜内的景别转换由**共同世界坐标与相机变换**处理，角色、桌面和道具共享变换；不能分别缩放各层凑远景。另画透视的细节插镜可通过剪切连接，不强求由一张平面图变出新视角，但须核对道具身份、接触阶段、材质和屏幕方向。准备首帧、接触帧、变色帧、反应帧与切点前后帧的检查图，再检查实际编码媒体。素材检查、600 帧等逐帧覆盖、正常速度回放、听音和用户验收是独立记录，未做的保持 pending。

- 每层保留原生画幅、比例、基点及裁切区域；建筑与其遮罩共享坐标，相机投影围绕可见开口正确配准。不得将窄远景拉满屏，也不无限放大模糊局部。
- 检查**完整运动路径的所有中间帧**：边缘 overscan、透明区、遮罩缝、场景重复、相机越界、裁切接缝、前景移开后的缺图。起止帧正确不足以通过。
- 区分合法退场与露底：近层可按设计离开画面，远景底图必须持续覆盖可见区域，相机在其有效范围内运动；不能把所有层一律钳在屏内，也不能拉伸远景补洞。开口遮罩、门扇与铰点随同一空间变换，避免角色被门缘截断或建筑重影。
- 背面用有效背面 cel，不能“背脑勺 + 正面身体”。保留关节连接、双腿中间分开、手与道具握点、脚底落点和肢体长度；局部动作不添加残影式多余四肢。场景/表情切换不重置道具归属。
- 光效服务现场光源和动作，在原画上局部作用；不以整屏蓝光、粒子或噪声掩盖设计/接触问题。
- 状态按绝对时间或帧编号确定，不能依靠上一次渲染累加。缓存/乱序/续渲应得到相同画面；跨切动作沿同一时间线，保存帧率及切点前后状态。
- 已确认角色、眼睛、素材、文案和音轨按指纹复用。修改镜头只重算受影响画面，不顺便重配音、重混或批量重生图。确需新增素材/费用时按原授权边界处理。

## Whole-film acceptance

技术检查与创作审阅分开记录，失败项标出镜号/时间点并修复；不能只写总分或“渲染成功”。先核对实际制作是否仍与用户确认的导演提案及规则表一致；出现新的触发、范围、附带接触或跨镜状态矛盾时，修正受影响提案并重新确认，不能靠遮挡或特效掩盖。

1. **全覆盖：** 核对 ledger 覆盖授权区间无缺漏/重叠；逐行审阅信息、层次、素材变化或合理复用、镜头动机和停点。分别记录开头、正文与结尾结果，不能以前 3 秒的丰富度代表后面。
2. **静帧与运动：** 每镜首/中/尾及最大位移拼板；对遮挡、相机揭示、换表情、关键动作和剪辑接点取密集运动条，特别核对遮挡换序的前后帧、门槛穿越与近层清屏后的完整底图。再查实际编码视频的同一区间，避免只看合成器静帧。检查目标画幅可见动作、全身/近景边界、左右手与腕肘归属、脚底/地影和背景共同运动，以及空间/身份/色彩、主体层级、安全区和字幕；将实际结果和证据记入 `quality_review`。
3. **代码验证：** 全运动路径边界、遮罩与连续性；选多个镜头乱序/反序取帧比对确定性；动作内切的道具与肢体轨迹匹配；核验输出时长/帧数、完整解码及保留媒体指纹。自动检测不等于语义/审美验收。
4. **完整回放：** 从头到尾正常速度看画面与声音；疑似瞬闪、跳变、拖沓或露边区间再慢放，最后回到正常速度。检查主体信息停滞、同构图远距离重复、无动机推拉和注意力争抢。无法实际回放/听取时明确标记缺失，不伪称检查通过。
5. **字幕与声音：** 保持实际语音对齐、语义完整的单行字幕，检查 sidecar 和编码画面的阅读时间/断句/无漏重错序。沿用已确认项目的字体、字号、位置和强调方式；没有已确认字幕样式时，按实际比例、可用字体和安全区先记录一套克制可读的候选，并在样片中确认，不能照搬 B4 恐怖字效或未经检查的固定字号。沿用 [B 声音系统](autopilot-sound-system.md)：清晰旁白、符合场景的克制底色、必要因果 SFX，不能用音效数量代替视觉丰富度。不继承 B4 固定 Brian；已确认录音继续复用。
6. **交付与恢复：** 保存 ledger、素材/相机状态、checkpoint、媒体指纹和 QA；保留旧版本，只修受影响部分。画面局改不改变已确认音轨、文案或字幕时间；核验复用源指纹与音频流，重编码的未改画面按记录的容差比对，不能声称压缩视频字节相同。交视频时同时给已核实的绝对视频路径及所在文件夹链接。样片批准、后续制作、付费和发布仍是分开的权限。

**通过口径：** 技术通过、内部逐镜视觉审查与用户实际观感分别记录。当前横屏画风及接触/剪辑基准为附带的 Midas R3 v1 20 秒试片；原生竖屏另附 Midas V5 实片和从该实片抽取的开场、全身及手臂方向板，横屏参考与 `demo` 保留。本次 V5 正面反馈严格限于当前这支 Midas 竖屏版本的画面，不推导 Kingdom 获认可、独立听审通过或发布许可。此前有效批准保留；新脚本、长片、多角色及新比例/改稿按受影响范围独立审阅。基准包文件校验、路由与 `quality_review` 记录核对都不承诺自动达到样片观感，也不能补签未完成的回放、听审或用户验收。

## Default audiovisual completeness

Selecting B8 automatically requires the [B1–B9 final delivery completeness gate](b-delivery-completeness.md) together with the existing B8 style/creative gates. Produce sample-directed captions, causal SFX and suitable background music by default, then verify each in the actual final MP4. Missing components, unchecked review or unavailable tools block a complete/pass claim. Sidecar captions, downloaded audio or successful encoding are insufficient. Keep the approved cartoon drawing/contact poses, restrained semantic captions and story-led scene/contact sounds; choose fitting music without importing another style’s visual effects. Document explicit user exemptions and narrative local silence under the shared gate; production difficulty is not an exemption.

```sh
node scripts/b-delivery-completeness.mjs init --style B8 --ratio 16:9 --media /absolute/candidate.mp4 --output /absolute/completeness-review.json
node scripts/b-delivery-completeness.mjs check /absolute/completeness-review.json
```

Use the actual requested ratio and output path. New records start unchecked. The script verifies evidence completeness; truthful full-output watching/listening and the existing style acceptance remain necessary. Existing sample approvals and rights decisions retain their original scope.
