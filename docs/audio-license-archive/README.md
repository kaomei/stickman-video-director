# Audio license source archive

These original web captures document the provenance of the Code Engine audio library. The manifest records their original source URLs and SHA-256 hashes. The files are plain-text snapshots.

The installed Skill carries the license texts, attribution, acquisition records and official records used by offline verification and export. See the [audio library documentation](../../skills/directing-stickman-videos/references/b-audio-library.md) for usage and the [archive manifest](manifest.json) for source captures.
