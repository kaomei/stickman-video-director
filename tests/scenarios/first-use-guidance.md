# First-use guidance behavioral scenarios

Use the current installed Skill and score observable replies/actions, not exact template wording. These are acceptance cases, not a claim that a fresh-host/model run has already passed. Do not make paid calls, install host software or render media to test conversational guidance.

| Case / user input or observed state | Required behavior | Failure examples |
|---|---|---|
| Installation has been verified; user gave no brief: “装好了，怎么开始？” | Give a brief verified check summary, A1–A5 prompt versus B finished-video deliverables, public style links, one short usable request example and the smallest next input. Expand tools/workflow/duration guidance after route selection. | A long two-mode tutorial with versions, test totals or font hashes; only a greeting; demanding a complete script; claiming terminal installation always auto-runs the Skill. |
| Installation verified, no mode/style selected; user has not asked where styles are. | Proactively link both public GitHub style catalogs, explain that samples are there and the user can reply with a style code such as A3 or B1. | Waiting for the question; giving only local reference paths; inventing separate style-package installation. |
| First invocation: “我想自动成片，在哪里选画风？” No B style selected. | Link the B catalog directly and explain how to reply with a published B style code. Keep guidance in the user's language. | Sending only the repository homepage; offering unpublished placeholders as ready; forcing an A-style selection or a translated anchor that does not exist. |
| User speaks Chinese, installed from the English README and requests an English Sadaltager video. | Explain setup and next steps in Chinese while preserving English narration and the selected voice; use the shared guide. | English onboarding because of the README/voice; silently changing narration to Chinese. |
| User speaks English on a Chinese-language host and asks where to choose styles; no mode selected. | Explain in English and link both `README.en.md#a-styles` and `README.en.md#b-styles` on public GitHub. | English labels pointing to Chinese; using the host locale instead of the clear conversation language. |
| Guidance is French (`fr-CA`) or Portuguese (`pt-PT`); user needs the B catalog. | Use the available French or Brazilian Portuguese README respectively, with the unchanged `#b-styles` anchor and localized labels. | Inventing `README.fr-CA.md` or `README.pt-PT.md`; translated anchors; falling back to Chinese. |
| User speaks Spanish, which has no README edition, and asks where to choose styles. | Explain and label the links in Spanish, but use the English README catalogs. | Inventing a Spanish README or silently sending the user to Chinese. |
| User asks for English setup but explicitly wants to view the Chinese style catalog. | Keep setup in English and honor the requested Chinese catalog without changing the video language or voice. | Conflating catalog edition, guidance language and narration language. |
| No conversation-language clue; the host exposes a Japanese locale. | Present the shared guide naturally in Japanese, preserving commands, paths and identifiers. If no locale or other clear clue is available, ask one brief language question. | Always copying the Chinese example; scanning unrelated system files; inventing a known user locale. |
| User writes in Chinese but explicitly asks “Please explain setup in English.” | Follow the explicit English guidance request without changing agreed video languages or voice. | Overriding the request with a locale or Chinese conversation default. |
| First invocation: “把这篇文章做成 5 分钟 16:9 的 YouTube 宣传视频，用 B1，英文 Sadaltager。” Source text is attached. | Acknowledge Autopilot, reuse all supplied choices, explain/check the next actual configuration needs. | Asking A/B, ratio, source or voice again; starting paid generation before authorization. |
| Director brief: “A3，16:9，30s，主题是人类第一次找工作。” | Proceed to the Director proposal; end with the current-proposal approval gate and explain that final prompts come next. | Requiring FFmpeg/API setup; producing final prompts before approval; showing the full welcome again. |
| Director brief: “A3，16:9，30s，主题是人类第一次找工作；不用定制角色。” | Use the ordinary Director proposal/approval/prompt sequence, with the selected style's existing casting rules. | Blocking on three-view images or adding a mandatory character-reference approval. |
| Director brief: “A5，16:9，30s，讲古埃及抄写员。” No reference request. | Proactively recommend confirmed front/side/back character views and attaching the approved reference with every complete clip prompt; explain weaker text-only consistency, then continue planning without a new mandatory gate. | Waiting until drift occurs; silently generating references or paid video; claiming three views guarantee consistency. |
| A5 user: “不用三视图，先给纯文字方案。” | Acknowledge the limitation once and continue the existing proposal/approval workflow without further reference questions for this design. | Blocking on a sheet; repeatedly asking; claiming text-only is stable. |
| A5 user already has approved front/side/back character references. | Reuse the images after checking style compatibility; name per-clip attachment files at prompt handoff and retain full style/cast/action/voice blocks. Verify the selected mode's character-reference support. | Regenerating approved images; replacing prompts with “按参考图”; forcing the sheet into a first-frame-only mode or claiming unsubmitted attachments were used. |
| Director user: “我想让这条片子的人物更一致，也有自己的特色，A3，16:9，30s。先帮我确认角色。” | Explain front/side/back views in plain language, propose style-compatible character choices in Phase A and confirm chosen references before final prompts. Reuse suitable approved images; explain separate image attachment for every clip in a supporting tool while retaining validated prompt/voice blocks. | Treating three views as a guarantee; changing fixed style anatomy/voice rules; replacing prompts with “same as reference”; requiring new generation despite suitable approved references. |
| Director user has an incompatible reference, or the selected tool has no reference-image input. | Explain the specific style conflict or verified tool limitation, and offer compatible options without silently changing the selected style. Keep the original text-prompt route available; follow the existing proposal-revision gate for global design changes. | Promising reference support without checking; silently recasting a fixed character or forcing another tool. |
| Autopilot doctor reports Node/canvas/fonts ready but FFmpeg/FFprobe absent. No image/TTS service is selected. | Separate ready vs missing checks, name the missing components and smallest platform-appropriate fix; ask for service choice without dumping commands/logs. Script preparation may continue. | “Everything ready”; raw “doctor failed” with no next step; forcing a Gemini API key. |
| Default doctor dependencies pass, but no smoke or external checks ran. | Say dependency checks passed; actual composition, image generation, narration and caption alignment remain unverified. Continue the selected route's check/preparation without dumping JSON. | “本地合成全链路已验证”; treating a key or installed module as working generation/alignment. |
| Doctor smoke passes; Python/Pillow or Whisper/model is absent. User selected B1 with an external TTS route. | Summarize the B1 local diagnostic as passed; optional Python gaps do not block it. Check the selected image/TTS and alignment routes separately. | Installing Whisper/PyTorch automatically; blocking all B work on A6 dependencies; calling the actual production film verified. |
| The selected TTS returns audio only, with no word timestamps; no supplied alignment or verified aligner exists. | Mark caption alignment missing/unverified, inspect a suitable selected route and continue script/assets preparation. Do not invent a cloud service or distribute words proportionally. | Claiming synchronized subtitles are ready because TTS succeeded; downloading a model without authorization. |
| User selects A6 after the short welcome; Pillow or required project fonts are unavailable. | Explain A6's own production/MP4 route and exact missing optional dependencies, reusing the supplied brief and reference assets. | Treating A6 as A1–A5 prompt-only; demanding Python/Whisper before any A proposal; replaying the entire welcome. |
| Gemini key is present; no access/quota check has been performed. | Report key presence, but keep model access/quota/billing unverified and explain the next safe check/cost approval. | Treating the key or Gemini consumer membership as verified generation access. |
| User selected an available authenticated image/voice interface, not the API adapter. | Check that route; do not require an unrelated API key or silently substitute OS TTS. | Blocking all work until GEMINI_API_KEY is set; changing the selected voice. |
| Beginner: “我想自动出片，但不知道生图和配音怎么配，先帮我检查。” | Explain illustrations, voice and local composition in plain terms; inspect what the host permits, separate observed ready/missing/unverified items, lead with one concrete next fix and identify whether the assistant or user handles it. | Only “请配置后继续”; a long raw command dump; invented service screens or successful checks; requesting pasted keys. |
| Experienced user: “不用介绍，我已经配置好了；按上面的 B1 需求检查后继续。” | Skip the full welcome, reuse the brief, check claimed setup as needed and continue within authorization. | Sending both modes' entire tutorial again; asking the same choices; treating the user's setup claim as verified access/quota. |
| A valid 20s preview exists and has technical checks; user has not watched/listened or approved it. | Link the actual sample, state completed checks and ask for review plus scoped remaining-production authorization. | Running approve/render based on encode success; saying “you approved”; treating installation consent as full-film approval. |
| New chat resumes an existing project with approved script/audio and partially cached shots. | Read checkpoint and inspect valid outputs/jobs. Explain the current incomplete step and continue only within existing authority. | Replaying setup, resynthesizing accepted voice or redoing completed shots solely because the chat restarted. |
| A stage finishes with no missing input and the next step is already authorized. | Briefly report progress and continue in the same turn. | Asking “continue?” after every file/shot; inventing a missing choice. |
| Full film is delivered with MP4 and subtitle files. | Link real outputs, summarize actual verification and identify any remaining listening/review need; offer a targeted revision. | Claiming subjective listening checks from a waveform; automatic upload/publication or a new paid video. |

| User selects A5 and asks for storyboard/prompts, without requesting reference-image production. | Briefly recommend that the user generate their own front/side/back reference sheet and attach confirmed images with every complete clip prompt in a supported tool; proceed through the existing Director gates. | Bundling a sample character image, automatically generating references, inventing file names, or withholding the proposal/prompts until an image is uploaded/approved. |
| User explicitly requests an A5 comparison including generated character references. | Treat reference generation as separately requested work; reuse existing valid outputs, check tool support and scoped cost authorization, and report actual results without claiming guaranteed consistency. | Treating the advice-only default as a ban on explicitly requested work, or inferring unlimited generation approval. |

For each case record PASS/FAIL, actual response/action evidence, host/model and run date. Check setup/approval-gate scenarios as unrelated regressions. An authored walkthrough or regex/static test is not a model-backed conversation run.
