# Channel art — pick one pair, upload, done

Six files, three complete looks. Each look is a banner + a matching profile picture.
Open **`preview-banners.png`** and **`preview-avatars.png`** first — they show every option
at the two sizes that matter: the full banner, and what a phone actually shows.

| Look | Banner | Profile | Personality |
|---|---|---|---|
| **A · Deep space** | `banner-a-deep-space.png` | `avatar-a-deep-space.png` | The flagship. Dark, cinematic, matches the thumbnail set. Best if you want the channel to feel like a "studio". |
| **B · Warm paper** | `banner-b-paper.png` | `avatar-b-paper.png` | Light background, ink drawing, marker arrow. Stands out because almost every animation channel is dark. Best if you want to feel hand-made and human. |
| **C · Signal split** | `banner-c-signal.png` | `avatar-c-signal.png` | Hard red/black split. Highest contrast at small sizes. Best if you want maximum punch in a crowded feed. |

**Recommended for StickVerse: A**, because it matches the six thumbnails in
`../thumbnails/`. Consistency between banner, avatar and thumbnails is what makes a small
channel look established. If you would rather stand out, take **B** and keep it everywhere.

A ready-to-upload pair of the recommendation is already in `../final/`:
`final/banner.png` and `final/profile.png`.

## Upload steps

1. **Profile picture** — YouTube Studio → **Customisation → Branding → Picture**
   → upload the 800×800 avatar. It renders as a circle, which is why every design is already
   circular inside the square.
2. **Banner** — same page → **Banner image** → upload the 2560×1440 file.
   YouTube will show you the crop preview. The name and character should both stay inside the
   frame *without* moving the crop slider.
3. **Watermark** (recommended, 10 seconds) — Branding → **Video watermark** →
   `../watermark-150.png`, display: **Entire video**.
4. Check on your phone. If the name is cut off on your phone, the banner is wrong — not the
   phone. All three options are drawn inside the 1546×423 safe box, so they cannot be cut off.

## Changing the words (optional)

Everything is generated by `../tools/make_channel_art.py`, so the channel name, tagline and
schedule line are one-line edits:

```bash
cd stickverse/tools
# edit the strings in banner_a() / safe_lockup(...) calls
python make_channel_art.py
```

Useful knobs:

- `safe_lockup(img, 176, "AI STICKMAN STORIES", "New Shorts daily · Deep dives every Friday", ...)`
  — `176` is the wordmark size in px. Raising it grows the name; it is already sized to fit the
  phone-safe box.
- `fig_h = 300` — character height. Keep it between 260 and 320 or he stops fitting the box.
- `safe_lockup(..., x=SX0 + 46, mid_y=...)` — move the text block. `SX0`/`SY0`/`SX1`/`SY1` are
  the safe-box edges, so offsets are always measured from safety, not from the canvas edge.

If your channel name is **not** StickVerse, change `"STICKVERSE"` in `draw_wordmark()` and the
name will re-fit automatically.
